# Mi receta: arepas de queso 🫓

Este proyecto guarda mi receta favorita y la historia de por qué me gusta. Lo hice en el curso de Formación en GitHub para practicar cómo guardar cambios con Git y subirlos a GitHub.

## Archivos del proyecto

- [`receta.md`](receta.md): ingredientes, tiempo y pasos de preparación.
- [`historia.md`](historia.md): de dónde viene la receta y por qué la elegí.

## Lo que practiqué

- Hacer commits pequeños con buenos mensajes (`git add` y `git commit`).
- Revisar el historial con `git log --oneline`.
- Conectar el proyecto con GitHub y subirlo con `git push`.
